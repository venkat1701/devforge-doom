Learning to Play DOOM Zero-Shot: Recurrent PPO with a Tiered Map Curriculum and Scoring-Aligned Shaping

Track 1 "Can It Play DOOM?" · ViZDoom 1.3.3, Freedoom 2, skill 3 · official doom_env observations only

1. USP

  • Procedural tiered curriculum that mirrors the hidden suite. Our own UDMF generator builds small maps in the four evaluation tiers (combat arenas; multi-room with doors; keycard → locked door → exit; gauntlet) using the template map's door/exit conventions. Every map is validated in the real engine against the official wrapper's own door/lock parser. Full Freedoom levels cannot be finished inside 60–120 s, so without this the agent almost never experiences an exit or a key.
  • Training-only reward aligned with every scoring category, with potential-based route shaping toward the next required objective (Ng, Harada & Russell 1999) and an aim-cone ammunition-discipline term computed from the agent's own sensors.
  • Fast, auditable training. Background engine prefetch and 256 parallel simulators raised throughput from ~1.3k to ~6.5k transitions/s; every checkpoint is selected on fixed-seed, held-out maps through the real submission agent.

2. Neural architecture

rays(64×7) → circular Conv1d×3 → 256  |  entities(32×(5+type emb)) → shared MLP → mean & max pool → 64+64
vitals(17) + previous action emb(16) → 64  |  RGB-D 4×60×80 → CNN → zero-initialised projection (added)
fusion 448 → FC 512 → GRU 512 → policy (56 button combinations)  ·  value head (training only)
  • Variable numbers of enemies: entities are encoded by a shared MLP and pooled (mean and max), so the network is permutation-invariant and handles 0–32 visible objects.
  • Ego-centric rays (64 directions, hit type wall/door/locked/enemy/item) use circular convolutions; no global coordinates are observed.
  • Training-only signals: privileged state is used only to compute the training reward; the value head is dropped at export and the submitted policy uses the official observation only.
  • Pixel encoder: Nature-DQN CNN on RGB-D. A residual IMPALA encoder was trained in parallel and matched it within noise (held-out proxy 17.31 vs 17.60, 800 episodes each), so the smaller encoder was kept.
  • Inference: p50 1.1 / p99 1.4 ms per decision (budget 40 ms), 2.64M parameters.

3. Spatial memory

The agent never sees global positions, so memory must be learned. The 512-unit GRU carries an episode-long recurrent state (reset only at episode start). The submitted model has no explicit map or pose memory; all spatial knowledge lives in the recurrent state. The tier-3 skill – remembering a locked door after finding its key – was measured directly: held-out locked-door openings rose from 0.04 to 0.74 per episode once the curriculum contained key–door maps.

4. Training & exploration pipeline

Algorithm. Synchronous recurrent PPO (clip 0.1, GAE λ=0.95, γ=0.99, 128-step rollouts, 4 epochs, Adam 2.5e-4 annealed), 64–256 simulator processes with background prefetch of the next episode's engine. Runs warm-start from the previous best checkpoint (weights carried over).

Maps. 240 generated maps (tiers 1–4) + 41 Freedoom 1/2 levels + 5 ViZDoom scenarios. 24 generated maps + the template map and Freedoom 2 MAP17–24 are held out for selection; another 24 generated maps and MAP25–32 are reserved for one final check.

Exploration. Episodic count-based coverage bonus (new 128-unit cell), potential-based route shaping toward the next required objective, and mild sampling at inference (temperature 0.25), which halved back-and-forth looping between two rooms (6 → 3 of 42 tier 2–4 episodes) compared with greedy decoding.

6. Rules compliance

Every action is chosen by the trained network from the official observation dictionary. Privileged state (positions, keys, sector heights) is used only in the training reward and the training-only critic. No scripted control, path planner or aimbot exists in submission/. At inference one fixed, state-independent action combination (SELECT_NEXT_WEAPON alone) is removed from the vocabulary, which cut time spent on fists while holding ammo from 41% to 7%; the network still chooses every action among the other 55. Evaluation runs the vanilla engine; curriculum maps are used only for training.

7. Limitations and next steps

  • Full-length Freedoom levels remain hard (no exits within the cap): long-range navigation needs stronger memory, e.g. a learned ego-centric occupancy grid.
  • The binary turn buttons give a minimum turn of ~7–14° per decision; aiming relies on timing shots.
  • Next: a learned ego-centric occupancy map fed to the policy (spatial memory for key–door backtracking), asynchronous PPO (the lockstep learner, not the CPU, limits throughput), behaviour cloning from scripted demonstrations on key–door maps, and hierarchical sub-goal policies.
